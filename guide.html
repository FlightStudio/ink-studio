On your computer

Prepare the machine, then the database

Do the machine setup once. Then start Postgres and apply the identity tables.

  1. Install Docker Desktop and leave it running. On Linux, Docker Engine plus the Compose plugin is enough. If docker compose says permission denied, open a new terminal after your user is in the docker group, or run the compose commands with sg docker -c '…'.
  2. Install Node.js 22 from nodejs.org.
  3. In a terminal: corepack enable then corepack prepare pnpm@10.33.4 --activate.
  4. Clone this repository and check out the branch cursor/ink-studio-guide-8700.
  5. pnpm install

Postgres 17 on port 5434

From the repository root, with Docker running:

cp .env.example .env
cp tools/.env.example tools/.env
docker compose up -d
docker compose ps
pnpm db:migrate

docker compose ps should show the postgres service as healthy before you migrate. pnpm db:migrate creates users, organizations, and organization_users.

Look at the tables in the browser with Drizzle Studio. It uses the database config already in the repo, so you do not install a second Postgres or a separate database app:

pnpm db:studio

Leave that terminal open while you browse users, organizations, and organization_users. Stop it with Ctrl+C. The connection it uses is:

postgresql://postgres:postgres@127.0.0.1:5434/ink_studio

That password is only for this local database. Do not reuse it anywhere else. Stop the database later with docker compose stop. The data stays in the Compose volume.

The same tables from the terminal:

docker compose exec postgres psql -U postgres -d ink_studio -c '\dt'

Open the website

After migrate succeeds, seed one local user and start Next.js:

cp apps/web/.env.example apps/web/.env.local
pnpm seed
pnpm dev

Open http://127.0.0.1:3000. The home page sits on the warm desk colour. It says Signed in, Ink Studio in the serif title face, then dev@inkstudio.local · Ink Studio and a button, Open the style guide. Health is http://127.0.0.1:3000/api/health and answers {"ok":true}.

The stationery style guide is http://127.0.0.1:3000/styleguide. With the dev server already running, this writes .local/screens/styleguide-1440x900.png and .local/screens/styleguide-ipad.png:

pnpm screens /styleguide

Docker has to be running for the screenshots. The first run downloads the Playwright browser image.

Running pnpm seed again keeps that same user and organization. The password in the connection string is only for this local database.

An iPad on the same network needs DEV_LAN_HOST set to this computer's LAN address in the root .env and in apps/web/.env.local, and NEXT_PUBLIC_PLATFORM_URL=http://<that-address>:3000 in apps/web/.env.local. Restart pnpm dev, then open that address on the iPad. The dev server listens on port 3000 on every interface.

Just landed

Step 5. Stationery design system

Open /styleguide while pnpm dev is running. You should see one sheet of letter paper on a warm desk, the way the editor will look:

  • A small white bar floats over the top edge of the sheet: undo, redo, align left, centre and right, and Library. Hover a button for its name. Undo and redo follow the alignment you pick.
  • The sheet says Start with a blank sheet. That line and the page title, Quiet stationery, are the only places the serif display face appears.
  • Under the sheet: the letter title, Saved, a View menu that switches between On the desk and As printed, and Delete, which asks before it does anything.
  • Library slides in from the right with two tabs, Drawn and From a photo. Photo doodles carry status pills, and Erase opens a small eraser size slider.
  • On the left, the legend: every stationery colour with its name, the four type sizes with real sample text, and the four status pills.

On an iPad the legend moves above the sheet. The ink colours a person writes with arrive in step 6. The legend shows the stationery colours only.

The sheet is plain paper colour for now. The scanned paper texture lives in project-post, which is not in this repository. Copy project-post's paper.png to apps/web/public/images/paper.png and the sheet picks it up without a code change. Until then the browser logs one missing image on the style guide.

Checked: pnpm lint, pnpm typecheck, pnpm test, the style guide and home page in Chromium and WebKit, and both screenshots.
