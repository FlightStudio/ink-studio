On your computer

Prepare the machine, then the database

Do this now. The database commands stay locked until docker-compose.yml exists.

  1. Install Docker Desktop and leave it running. On Linux, Docker Engine plus the Compose plugin is enough.
  2. Install Node.js 22 from nodejs.org.
  3. In a terminal: corepack enable then corepack prepare pnpm@10.33.4 --activate.
  4. Clone this repository and check out the branch cursor/ink-studio-guide-8700.
  5. pnpm install
  6. pnpm lint, pnpm typecheck, and pnpm test should pass. There is no website yet.

Postgres 17 on port 5434

Not in the repository yet. Step 3 adds Compose, the identity tables, and pnpm db:migrate. When that lands, this box becomes the thing you run, and the connection is:

postgresql://postgres:postgres@127.0.0.1:5434/ink_studio

That password is only for this local database. Do not reuse it anywhere else.
